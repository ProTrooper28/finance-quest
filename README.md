# Finance Quest 
AI-powered gamified financial literacy platform.

Build a modern, premium, AI-powered gamified financial literacy platform called "FinQuest" (replace with final app name if needed).

The platform is designed for students, first-time earners, young professionals, and anyone starting their financial journey. Instead of teaching through videos and quizzes, it should provide interactive simulations that allow users to learn by making real financial decisions in a risk-free environment.

========================

DESIGN REQUIREMENTS

========================

- Premium fintech UI

- Dark theme with blue and purple gradients

- Glassmorphism cards

- Smooth animations and micro-interactions

- Mobile-first responsive design

- Minimal, clean, and modern layout

- Use Inter or Poppins font

- Professional look inspired by Duolingo, CRED, Zerodha and Notion
